Books API

Ejercicio 05 · Desarrollo de Sistemas Web

¿Qué es?

Una API REST hecha con Express para gestionar una lista de libros. Cada libro tiene la forma { id, title, author } y el id lo genera el servidor. Los datos se guardan en memoria: al reiniciar el servidor vuelven los tres libros iniciales.

Endpoints

Método Ruta Éxito Errores
GET /books 200 array de libros —
POST /books 201 el libro creado 400 si falta title o author
GET /books/:id 200 el libro 404 si no existe
DELETE /books/:id 204 sin cuerpo 404 si no existe

Errores

Todos los errores se devuelven en JSON con la forma { "error": "..." }. Una ruta que no existe responde 404 con { "error": "unknown endpoint" }.

Prueba la API con requests/books.http (extensión REST Client) o con curl.
